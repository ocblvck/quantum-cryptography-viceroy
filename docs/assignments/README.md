# Assignments

This directory contains assignment briefs for the undergraduate research group.

Each assignment is written to fit the existing repository structure. Before starting a new assignment, students should read the brief, review the referenced files, and record experimental results in [../EXPERIMENT_LOG.md](../EXPERIMENT_LOG.md).

## Available Assignments

1. [Assignment 01: Implementing B92 and E91](assignment_01_b92_e91.md)
2. [Assignment 02: Attack and Noise Analysis](assignment_02_attack_noise_analysis.md)

## General Expectations

1. Work inside the existing repository structure rather than building separate scripts or frameworks unless an assignment explicitly asks for that.
2. Reuse the protocol base classes, analysis utilities, tests, and experiment patterns already present in the repository.
3. Record experiment settings, observations, and conclusions in [../EXPERIMENT_LOG.md](../EXPERIMENT_LOG.md).
4. Keep code changes focused and readable.
