# Notebooks Directory

Jupyter notebooks for interactive learning and exploration.

## Available Notebooks

1. **01_QKD_Introduction.ipynb** - Introduction to quantum cryptography
2. **02_BB84_Deep_Dive.ipynb** - Detailed BB84 exploration
3. **03_Attack_Exploration.ipynb** - Interactive attack simulations
4. **04_Noise_Effects.ipynb** - Visualizing noise impacts
5. **05_Research_Template.ipynb** - Template for new experiments

## Getting Started

```bash
# Install Jupyter
pip install jupyter

# Start notebook server
jupyter notebook
```
